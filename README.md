# 🌳 Infix to Postfix Converter (C)

A C program that converts intfix expressions into postfix expressions using binary expression trees and a stack data structure.

## 🚀 Features
- Uses custom stack and binary tree implementations in C
- Parses space-separated postfix expressions
- Reconstructs and prints the fully parenthesized infix notation

## 🛠️ Technologies Used
- **Language:** C
- **Concepts:** Binary Trees, Stacks, Pointers, Memory Management (`malloc`/`free`)

## ▶️ Usage
Compile and run the program using GCC:
```bash
gcc main.c -o postfix_to_infix
